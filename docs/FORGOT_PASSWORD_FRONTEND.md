# 忘记密码功能 - 前端说明

## 📱 功能概述

忘记密码功能采用三步流程，帮助用户通过手机验证码重置密码。

## 🔄 三步流程

### 步骤 1: 验证手机号

**界面元素:**
- 手机号输入框（带图标）
- "发送验证码"按钮

**交互:**
1. 用户输入11位手机号
2. 点击"发送验证码"
3. 前端验证手机号格式
4. 调用 API 发送验证码
5. 成功后进入步骤2，开始60秒倒计时

**验证规则:**
- 必须是11位数字
- 必须以1开头
- 第二位必须是3-9

---

### 步骤 2: 输入验证码

**界面元素:**
- 手机号显示（绿色背景）
- 验证码输入框（6位数字）
- "重新发送验证码"链接（60秒倒计时）
- "验证"按钮

**交互:**
1. 显示已发送验证码的手机号
2. 用户输入6位验证码
3. 点击"验证"按钮
4. 调用 API 验证验证码
5. 成功后进入步骤3

**倒计时:**
- 60秒倒计时
- 倒计时期间"重新发送"按钮禁用
- 倒计时结束后可重新发送

---

### 步骤 3: 设置新密码

**界面元素:**
- 新密码输入框（带显示/隐藏切换）
- 确认密码输入框（带显示/隐藏切换）
- "完成重置"按钮

**交互:**
1. 用户输入新密码
2. 用户确认新密码
3. 点击"完成重置"
4. 前端验证密码一致性
5. 调用 API 重置密码
6. 成功后跳转到登录页

**验证规则:**
- 密码至少6位
- 两次密码必须一致

---

## 📱 用户流程

### 正常流程
```
1. 点击登录页"忘记密码"
   ↓
2. 输入手机号 → 发送验证码
   ↓
3. 输入验证码 → 验证
   ↓
4. 输入新密码 → 确认密码
   ↓
5. 完成重置 → 跳转登录页
```

### 异常处理
```
手机号未注册 → 提示"手机号未注册"
验证码错误 → 提示"验证码错误或已过期"
密码不一致 → 提示"两次输入的密码不一致"
网络错误 → 提示"网络错误，请稍后重试"
```
